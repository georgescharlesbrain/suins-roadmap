# SuiNS Roadmap Website

This is the standalone, interactive roadmap website for the Sui Name Service (SuiNS).

It features:
- A live **Stats Ticker** querying total burnt `$NS`, treasury USD value, and the `$NS` token price directly from Sui RPC nodes and CoinGecko.
- A dynamic **Roadmap Explorer** to search and filter through shipped, building, and proposed features.
- Interactive **Feature Cards** with shareable deep link hashes, border flash highlight animation, strategic *why it matters* value propositions, precedents, and a three-button **Action Footer** (Build it / Discuss / Track).
- Prerequisite and unlock dependency navigation.

## Repository Scope

This repository is **public** and stands by itself as a Next.js web application.
